# Releases

Este proyecto es un sandbox de práctica para una jornada de capacitación, no un producto con release real. No hay versionado semántico, changelog, ni pipeline de release — no aplica y no se sobre-construye solo para tener el archivo completo.

"Deploy" en este repo significa: correr `uvicorn` (o `docker compose up -d`) localmente y validar contra `/health` y `/stats` — ver `docs/handbook/development.md`.
