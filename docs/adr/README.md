# docs/adr/

Decisiones de arquitectura cerradas, una por archivo (`NNN-titulo-corto.md`). Que la IA no reabra lo ya decidido: si una decisión está acá, un agente la respeta salvo que alguien la reabra explícitamente.

Formato mínimo por ADR: decisión · por qué · alternativas descartadas · estado (vigente/reversible/locked).
